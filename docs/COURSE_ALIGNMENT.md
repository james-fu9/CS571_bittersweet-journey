# CS571 React approach

The project uses the client-side React patterns taught in CS571, Fall 2026.

| Pattern | Project use | Lecture reference |
| --- | --- | --- |
| Functional JSX components, props and callbacks | Shared controls, reader and atlas interface | Week 4, `lec06-webdev1.pdf`, pp. 20–33 |
| State and immutable updates | Language, chapter completion and seals | Week 4, `lec06-webdev1.pdf`, pp. 34–35, 43 |
| Effects with cleanup | Map rendering, listeners and browser storage | Week 5, `lec08-webdev2.pdf`, pp. 9–13 |
| Stable list keys | Chapter and seal lists | Week 5, `lec08-webdev2.pdf`, pp. 17–20 |
| Context and localStorage | Shared journey state and saved progress | Week 6, `lec10-webdev3.pdf`, pp. 6–25 |
| React Router and HashRouter | Navigation and direct links on GitHub Pages | Week 6, `lec10-webdev3.pdf`, pp. 29–35; Week 8, `lec14-ai-assisted-dev.pdf`, p. 17 |
| Refs | Map containers and reader scrolling | Week 7, `lec12-webdev4.pdf`, p. 23 |
| Vite production build | Static deployment through GitHub Actions | Week 8, `lec14-ai-assisted-dev.pdf`, pp. 4–5, 12 |

The interface uses semantic HTML and CSS. No backend is required. Lecture slides are referenced, not redistributed.
