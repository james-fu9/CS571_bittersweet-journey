# Project implementation

**Authors:** Yanbing Chen and Ganrong(James) Fu

The basic nine-location journey is available on GitHub Pages.

- React components, Hooks, Context and HashRouter.
- Six-scene opening and the five-section My Hometown reader.
- Eight original bilingual project guides with three sections each.
- Interactive atlas, location maps, reading prompts and source links.
- Saved reading places for every chapter and unique chapter seals.
- A five-scene bilingual ending after all nine seals are collected.
- Responsive layouts, keyboard navigation, storage recovery and WebGL fallback.
- Automated checks and deployment.

Further refinement can deepen each guide's maps and add more chapter-specific visual interactions.

See [reader design](READER.md), [testing](VERIFICATION.md) and [credits](../ATTRIBUTION.md).
